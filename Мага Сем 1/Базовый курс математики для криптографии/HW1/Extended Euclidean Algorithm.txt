1) a = 261, b = 233
261 = 233 · 1 + 28
233 = 28 · 8 + 9
28 = 9 · 3 + 1
9 = 1 · 9 + 0
So d = gcd(261, 233) = 1.
Back substitution:
1 = 28 − 3 · 9
9 = 233 − 8 · 28, so 1 = 28 − 3 · (233 − 8 · 28) = 25 · 28 − 3 · 233
28 = 261 − 233, so 1 = 25 · (261 − 233) − 3 · 233 = 25 · 261 − 28 · 233
Answer: x = 25, y = −28, d = 1
Check: 261 · 25 + 233 · (−28) = 6525 − 6524 = 1
2) a = 119, b = 567
Forward pass:
567 = 119 · 4 + 91
119 = 91 · 1 + 28
91 = 28 · 3 + 7
28 = 7 · 4 + 0
So d = gcd(119, 567) = 7.
Back substitution:
7 = 91 − 3 · 28
28 = 119 − 91, so 7 = 91 − 3 · (119 − 91) = 4 · 91 − 3 · 119
91 = 567 − 4 · 119, so 7 = 4 · (567 − 4 · 119) − 3 · 119 = 4 · 567 − 19 · 119
Answer: x = −19, y = 4, d = 7
Check: 119 · (−19) + 567 · 4 = −2261 + 2268 = 7
3) a = 127, b = 246
Forward pass:
246 = 127 · 1 + 119
127 = 119 · 1 + 8
119 = 8 · 14 + 7
8 = 7 · 1 + 1
7 = 1 · 7 + 0
So d = gcd(127, 246) = 1.
Back substitution:
1 = 8 − 7
7 = 119 − 14 · 8, so 1 = 8 − (119 − 14 · 8) = 15 · 8 − 119
8 = 127 − 119, so 1 = 15 · (127 − 119) − 119 = 15 · 127 − 16 · 119
119 = 246 − 127, so 1 = 15 · 127 − 16 · (246 − 127) = 31 · 127 − 16 · 246
Answer: x = 31, y = −16, d = 1
Check: 127 · 31 + 246 · (−16) = 3937 − 3936 = 1
